# openwakeword_creation
it create the #openwakeword (open wake word) for you whatever you want to create you dream wake word it will create for you
but it can take so many time for train you wake word. just write the name on it and run the program it will create and download automatically

# how to create

open [google colab ](https://colab.research.google.com/)
create account on google colab click this link (https://colab.research.google.com/)
then upload the google colab 
then name what ever you want then click run it take Several hour to train and create the wake word
and generate the .onnx file for you
